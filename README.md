# Simple Interest Calculator

A simple bash script to calculate simple interest given principal, annual rate of interest, and time period in years.

## Project Overview
This project is part of the IBM Introduction to Git and GitHub course final assignment.

### Formula
Simple Interest = (Principal * Rate * Time) / 100

## Inputs
* **p**: Principal amount
* **t**: Time period in years
* **r**: Annual rate of interest

## Output
* **s**: Simple Interest calculated
